# Rock Paper Scissors

Play Rock Paper Scissors against the computer with a running score.

Built with plain **HTML, CSS and JavaScript**. No libraries, no build step.

## How to run

Download or clone this repo and open `index.html` in your browser.

```bash
git clone https://github.com/Ddharsh1707/rock-paper-scissors.git
```
